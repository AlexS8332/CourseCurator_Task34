# eval/files — набор И-17: сценарии файлового агента

Четыре воспроизводимых сценария дня 34 (`F1.json` … `F4.json`) и две
посаженные карточки для F3 (`planted/`). Формат читает
`files.LoadScript(path)`; прогон — `curator files -script eval/files/F2.json -yes`
(план → авто-согласие → применение в worktree → проверки) и стенд
`bench -trial 17`. Стенд работает с **копией** курса во временном каталоге
(`git init`), сам каталог курса не меняется.

## Сценарий — `Script`

| Поле | Что |
|---|---|
| `id` | `F1` … `F4` |
| `goal` | цель словами — то, что человек пишет агенту (уровень задачи, не инструкция по файлам) |
| `expect.files_min` | затронуто файлов (git status worktree) не меньше; у F1 — 0 |
| `expect.files_allowed` | образцы путей, куда можно писать: префикс каталога с `/` или glob `path.Match`; пусто — любые из разрешённых (`docs/`, `demos/`, `templates/`, `.claude/skills/`, `tools/curator/`) |
| `expect.writes` | план должен быть с записью (`true`) или без (`false`) |
| `expect.checks[]` | проверки на worktree после прогона, см. ниже |

Ожидания `files_min` / `files_allowed` / `writes` проверяет
`files.Verify(run, script)`, проверки — `files.Checks(root, script, summary)`
(каждая — `files.Evaluate(root, check)`).

## Проверки — `Check`

| `kind` | Поля | Пройдена, если |
|---|---|---|
| `exists` | `path` | файл есть (не каталог) |
| `contains` | `path`, `text` или `pattern` | файл содержит подстроку `text` или совпадение RE2 `pattern` |
| `absent` | `path`, `text` или `pattern` | файл есть и **не** содержит; файла нет — не пройдена (чтобы «ложных нет» не выполнялось вхолостую) |
| `regex` | `path`, `pattern` | то же, что `contains` с `pattern` |
| `diff_within` | `path`, `text` (заголовок раздела markdown) или `range` `[от, до]` | все изменённые строки файла — внутри раздела: diff worktree к `HEAD` (грязное дерево, новые файлы через `add -N`) или `HEAD~1..HEAD` (после коммита); удалённые строки — по старой нумерации и разделу старого файла, добавленные — по новой |
| `quotes_verbatim` | `path`, `source` (образцы через запятую), `min` (доля, 0 — 1.0) | каждая цитата «…» длиной ≥ 25 символов (`range[0]` — свой порог) — подстрока одного из файлов `source` после нормализации `corpus.Normalize` (регистр, ё/е, кавычки, тире, пробелы) без `` ` `` и `*`; цитат нет — не пройдена |
| `coverage` | `pattern`, `source`, `min`, `text` или `path` | эталон — файлы `source`, где есть `pattern`; найдено — те, чей путь или имя файла (с расширением или без) упомянуты в `text` (пусто → `summary` прогона, `files.Checks`) или в файле `path`; доля ≥ `min` |

Пути — от корня с `/`. Все проверки — чистые функции над каталогом
(без модели): их же гоняет `script_test.go` на временных файлах.
