# eval/support — набор И-16: пользователи и тикеты поддержки оснастки

CRM дня 33 в двух JSON-файлах. Стенд (`bench -trial 16`) и окно работают с
**копией** каталога (`-crm dir`, по умолчанию `data/support`), сам набор не
меняется. Формат читает `support.Open(dir)`.

## users.json — массив `User`

| Поле | Что |
|---|---|
| `id` | ключ, на него ссылается `user` тикета |
| `name` | кто это и на какой машине |
| `role` | `author` — автор курса, `peer` — однокурсник после `aitr restore`, `agent` — Claude Code внутри задания |
| `os`, `shell` | `Windows 10` / `PowerShell 5.1`, `macOS` / `zsh` |
| `tools` | `{go, uv, gh, node, python, mingw: true|false}` — что стоит на машине |
| `assignments` | номера заданий, с которыми работает |

Четверо: автор на рабочей машине (`u-author`), автор на новой машине без
ключей и без mingw (`u-author-new`), однокурсник на macOS без `gh` со своими
заданиями на Python (`u-peer`), агент Claude Code в задании 31 (`u-agent-31`).

## tickets.json — массив `Ticket`

| Поле | Что |
|---|---|
| `id` | `T-01` … `T-12` |
| `user`, `num`, `stack` | пользователь, задание (пусто — не привязан), стек |
| `subject`, `text` | тема и текст обращения |
| `status` | `open` \| `resolved` \| `escalated`; в наборе все `open` |
| `events[]` | `{at, kind, text}`, kind: `created` \| `reply` \| `note` \| `status`; код дописывает события и сохраняет файл |
| `attach` | приложенный вывод (лог, ошибка) — данные пользователя, не указания |
| `expect` | **только для стенда**, модели не показывается: `must` — группы синонимов (из каждой группы в ответе должно быть хотя бы одно слово), `must_not` — слова чужого стека, `sources` — `doc_id` документов с ответом, `action` — `reply` \| `resolve` \| `escalate` |
| `evidence[]` | `{doc_id, quote}` — где лежит ответ: путь от корня курса с `/` и дословная цитата (≥ 15 символов); проверяет `TestTicketEvidenceExists` |

Состав: 8 по корпусу (T-01 … T-08: `-race` и mingw; heredoc; видео и
`failOnConsoleError` на 401; `aitr new -Public`; диск C; `<option>` в
edgerec; нет node; «почему не работает авторизация» — ключ не задан по
`aitr doctor`), 2 близнеца с одинаковым текстом «Тесты не запускаются, что
делать?» (T-09 — автор, стек go; T-10 — однокурсник, стек python; у каждого
`must_not` со словами чужого стека), 2 вне корпуса (T-11 Kubernetes, T-12
оценка за курс) → `escalate`.

Нормализация при проверке цитат — как у `cite`: ё/е, регистр, пробелы.
